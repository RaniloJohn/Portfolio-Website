# DESIGN.md — Ranilo John portfolio

## World
Network-closet labeling in a lit room: black steel rack hardware, printed label-maker tape, cable schedules.
Strictly monochrome UI; the only colour on the page comes from the portrait, project screenshots, and certification badges.

## Tokens (app/globals.css)
| Token | Value | Use |
|---|---|---|
| `--paper` | `#efefee` | page ground |
| `--tape-white` | `#ffffff` | white tape, Experience band |
| `--ink` | `#0e0e0e` | text, black tape, rules, primary button |
| `--ink-2` / `--ink-3` | `#3d3d3d` / `#5e5e5e` | secondary / tertiary text (AA on paper) |
| `--rule` | `#cdcdcb` | hairlines between rows |
| `--steel` / `--steel-2` | `#151515` / `#232323` | patch panel, footer |

## Type
Archivo Variable (self-hosted via `@fontsource-variable/archivo`, width axis 62–125).
- Display: `font-stretch: 110–118%`, weight 800, uppercase, tracking -0.03em.
- Tape labels: `font-stretch: 72%`, weight 700, uppercase, tracking +0.06em.
- Body: 100%, weight 400, tabular numerals everywhere.
JetBrains Mono only for the ASCII rack art (Fig. 1), which scales to its box with container units. No other monospace.

## Components
- `.tape` / `.tape--white`: printed label tape. Section headings are tapes; no eyebrows, no section numbers.
- Patch panel (hero): 24-port 1U panel; assigned ports link to sections, projects, labs, certs, CV, socials. Spare ports stay dark.
- Fig. 1: tonal ASCII art of a 14U lab rack, generated by `scripts/rack-ascii.py` into `data/rackAscii.ts`. Activity LEDs (`*`) flicker out of sync; this is the only looping motion.
- Labs table: a cable schedule (Port / Label / Type / Destination).
- Buttons: 4px radius; primary is solid ink with a 2px under-edge that compresses on press.

## Radius
Tape 2px · controls 4px · media 6px. Nothing rounder.

## Motion
One authored moment: port LEDs blink twice and hold on load (link-up), staggered by port number.
Everything else is state feedback only (hover, press, focus). Reduced motion disables animation.
